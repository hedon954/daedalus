# daedalus

daedalus 是一个以“输出带动输入”为核心的深入学习教练 Agent。它依托文件系统和现代 AI IDE，帮助用户围绕 repo、书、课程、论文等学习材料完成从目标澄清、深度阅读、实作验证到知识库沉淀的闭环。

当前第一阶段聚焦代码仓库学习：先把 repo 深度学习流程跑通，再迁移到更通用的知识材料。repo 可以来自 GitHub、GitLab、内部 Git 服务、压缩包或本地文件系统。

## 核心理念

- 先解决现实问题，再选择学习材料。
- 先建立第一性原理和 trade-off 框架，再阅读代码细节。
- 先跑通核心链路，再分析架构和逐行阅读。
- 先实现 mini demo，再迁移到真实业务问题。
- 先沉淀可复用知识，再进入下一个学习任务。

## Repo 学习流程

1. 澄清用户想学什么、为什么学、要解决什么现实问题。
2. 从第一性原理介绍目标背后的知识，并关联既有知识库。
3. 推荐并筛选少数高质量 repo，最好收敛到一个主 repo。
4. 结合目标和 repo 生成层层递进的问题路线图。
5. 本地运行 repo，从入口出发断点走完核心链路。
6. 分析架构、模块边界、设计模式、关键算法和 trade-off。
7. 深度阅读核心代码，并沉淀可迁移模式。
8. 设计并实现 mini demo，复现 repo 的核心能力。
9. 回到用户最初的现实问题，形成业务解决方案。
10. 总结归档到知识库，为下一次学习提供上下文。

## 目录结构

```text
crates/
  docs/                 项目设想、设计说明和开发文档
knowledge-base/         经过验证的长期知识库
system/
  bin/                  本地构建、启动和维护脚本
  config/               用户偏好与运行配置
  prompts/
    common/             跨学习材料复用的通用提示词
    repo/               代码仓库学习的分阶段提示词
  templates/            学习任务、上下文、看板等模板
workspaces/
  01-backlog/           待学习候选任务
  02-learning/          进行中的学习任务，WIP = 1
  03-completed/         已闭环归档任务
  04-abandoned/         已放弃或暂停任务
```

## 当前状态

这是初始化版本，重点是先把文件系统驱动的学习流程固化下来。确定性逻辑后续会逐步放入 `crates`，用于补足 AI Agent 在长期上下文管理、任务状态、知识归档和本地工具调用上的不稳定性。
