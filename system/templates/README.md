# Templates

Reusable filesystem templates for daedalus artifacts.

## Backlog

- [`backlog/item.md`](backlog/item.md)：全局 pre-learning candidate 模板。用于 `workspaces/backlog/<slug>.md`，不承载 active lifecycle state 或 learning artifacts。

## Repo Learning

- `repo/`：repo learning project 模板。
- `repo-topic/`：repo learning topic 模板。

## Review / Knowledge

- `review/`：复习计划和 session 模板。
- `knowledge/`：长期知识库条目模板，由 `daedalus knowledge template` 使用。
- `knowledge-system/`：知识体系萃取模板，供 skill 工作流参考。
