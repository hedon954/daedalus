# Topic Reviews

Topic-level reviews are independent from the topic learning lifecycle. They do not reopen completed stages; they help the user rebuild, apply, and repair understanding from already created artifacts.

Review questions must start from:

```text
业务目标 / 现实任务
  -> 现实制约
  -> naive solution 为什么失败
  -> 核心抽象 / 不变量
  -> 实现机制
  -> trade-off
  -> 对比最佳实践
  -> 可迁移模式
  -> 复习题 / 应用题
```
