# Review Template

Review 是挂载在已学习 topic/project 上的独立生命周期。它不重新打开 learning stage，而是帮助用户从第一性原理重建理解、暴露薄弱点并更新 mastery map。

## Files

- [`review-plan.md`](review-plan.md)：复习目标、模式和 source artifacts。
- [`mastery-map.md`](mastery-map.md)：掌握度地图。
- [`question-bank.md`](question-bank.md)：按 recall / rebuild / application / weakness-repair 组织的问题库。
- [`sessions/`](sessions)：每次复习记录。

## First-Principles Chain

```text
业务目标 / 现实任务
  -> 现实制约
  -> naive solution 为什么失败
  -> 核心抽象 / 不变量
  -> 实现机制
  -> trade-off
  -> 对比最佳实践
  -> 可迁移模式
  -> 复习题 / 应用题
```
