# Mastery Map

掌握度必须由证据支撑，不使用纯主观分数。

| Item | Kind | Level | Evidence | Weakness | Next Review |
| --- | --- | --- | --- | --- | --- |
| 待补充 | concept / invariant / flow / trade-off / pattern | unknown / weak / medium / strong / transferable |  |  |  |

## Level Rules

- `unknown`：还没有有效复述或应用证据。
- `weak`：能识别名词，但无法从现实制约推导。
- `medium`：能解释主流程，但边界条件仍需提示。
- `strong`：能独立重建并解释 trade-off。
- `transferable`：能迁移到新业务场景并说明适用边界。
