# Knowledge Base

这里保存经过校准的可复用知识。workspace 是学习现场，knowledge-base 是能力系统。

目录含义：

- `concepts/`：原子概念。
- `skills/`：能力条目。
- `patterns/`：可迁移模式。
- `problems/`：问题入口。
- `cases/`：案例证据。
- `source-maps/`：来源映射。
- `trees/`：技能树和学习路径。
- `drills/`：复习、迁移和批判练习。
- `index/`：人可读导航页。
- `site/`：可选前端投影。

机器索引见 `index.toml`，由 `daedalus knowledge index` 重建。
