# 01 目标对齐指南

## 已确认目标

- 学习对象：OpenAI Codex CLI / `openai/codex`。
- 学习重点：Agent 主循环、上下文管理、工具调用、沙箱/权限边界、整体架构地图。
- 预期产出：运行 runbook、问题路线图、架构笔记、核心代码精读笔记、mini demo。
- 学习方式：先建立全局地图，再沿一次真实请求的核心链路向下读代码。

## 本阶段验收

- `.daedalus/task-card.md` 已记录学习目标、现实问题、产出物、验收标准和暂不学习范围。
- 用户已经明确源码学习对象和重点，而不是只提出泛泛的“学习 Codex”。
- 下一阶段需要客观评估 `openai/codex` 是否适合深读，并确认源码拉取方式。

## 待用户确认

- 是否接受学习官方 Codex CLI 可能需要网络、登录、模型 API 或本地权限配置。
- 是否由 Agent 协助执行源码拉取，还是用户亲自运行 `source/pull_source.sh`。
- mini demo 是否只复现本地可验证的 Agent CLI 架构，避免依赖真实模型服务。

## 下一步建议

进入 `02-repo-scout`，围绕以下维度评估 `openai/codex`：

- 目标匹配：是否直接覆盖 Agent CLI、工具调用和沙箱权限。
- 学习密度：是否存在清晰入口、模块边界和可追踪核心路径。
- 可运行性：是否能在本机以最小命令启动或以测试替代。
- demo 可能性：是否能抽取出最小 Agent CLI 骨架。
