# Shared Context

`shared/` 只保存跨 topic 可复用的已验证知识。探索草稿、用户假设和专题内源码阅读应留在对应 `topics/<slug>/notes/`。

## Files

- [`runbook.md`](runbook.md)：跨 topic 复用的运行与调试入口。
- [`architecture-map.md`](architecture-map.md)：跨 topic 稳定架构边界。
- [`source-index.md`](source-index.md)：源码模块索引。
- [`glossary.md`](glossary.md)：术语表。
- [`evidence-registry.md`](evidence-registry.md)：可继承证据。
- [`transfer-patterns.md`](transfer-patterns.md)：可迁移模式。
