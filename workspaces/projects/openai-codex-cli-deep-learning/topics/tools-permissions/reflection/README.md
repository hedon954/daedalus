# Reflection

这里保存你在 topic 收尾阶段写下的主动回顾。

`notes/` 记录学习过程，`reflection/` 记录你完成一轮学习后真正沉淀下来的判断、变化和疑问。只有完成 closeout reflection，并经过 Agent challenge 与你确认后，才可以进入 `knowledge-base/`。

## 文件

- [`candidate-map.md`](candidate-map.md)：贯穿 01-09 滚动维护的候选知识表，10-reflection 负责查漏补缺、降噪和状态确认。
- [`closeout.md`](closeout.md)：你的主动回顾总结。
