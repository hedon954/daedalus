# 10 Archivist

这个目录记录 `tools-permissions` topic 的收尾循环。它不是最终知识库正文，也不是用户 reflection 的替代品。

当前循环：

```text
draft candidate map
-> closeout prompts
-> user reflection / challenge
-> selection
-> archive evidence
```

入口：

- [`01-knowledge-candidate-map.md`](01-knowledge-candidate-map.md)：daedalus 贪心扫描后形成的候选地图，全部保持 draft。
- [`02-closeout-prompts.md`](02-closeout-prompts.md)：基于候选地图生成的 closeout 追问。
- [`03-selection.md`](03-selection.md)：用户最终选择哪些候选归档、延后、删除或修订。
- [`04-archive-evidence.md`](04-archive-evidence.md)：最终归档证据和校验命令。
